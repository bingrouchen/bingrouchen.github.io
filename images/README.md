# 图片放这里 / Put images here

- 作品图片 / Project images: `projects/<项目id project id>/cover.jpg`, `01.jpg`, `02.jpg` ...
- 材料图片 / Material images: `materials/<材料编号 material id>.jpg`, e.g. `M-001.jpg`

文件名要和 `assets/js/data.js` 里写的一致。图片还没上传时，网站会显示灰色占位框。
File names must match those in `assets/js/data.js`. Until an image is uploaded, the site shows a grey placeholder.

建议把图片压缩到 2000px 宽、500KB 以内，网站打开更快。
Resize images to about 2000px wide and under 500KB so the site loads quickly.
